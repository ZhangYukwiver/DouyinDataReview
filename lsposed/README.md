# 安卓推荐流控制

本模块用于支持现代 Xposed API 102 的框架，可选作用域为抖音标准版 `com.ss.android.ugc.aweme` 和极速版 `com.ss.android.ugc.aweme.lite`。配置工具可在 Android 9 及以上运行。

### 保留官方版，单独安装助手

安装「推荐流控制」，导入桌面端导出的手机配置，点「设置自动划走」，在系统无障碍服务中启用「推荐流自动划走」。回到官方抖音的首页「推荐」后，助手在本机匹配当前视频可见的文案、作者昵称和话题。隐藏模式命中后向上划一次，只记录模式只统计命中。折叠的文案只能匹配屏幕上提供的部分，音乐规则和按频率插入视频需要框架模式。可随时在同一系统设置中关闭服务。

### 框架模式

1. 在 DouyinDataReview 的「设置 → 推荐流」保存屏蔽词、想看的词条及插入频率，点「导出手机配置」。导出时使用桌面端现有的词条搜索功能，每个词取一页候选普通视频。
2. 安装模块 APK，在 LSPosed 管理器启用模块并勾选实际使用的抖音或抖音极速版。打开「推荐流控制」，导入上一步的 JSON。
3. 首次启用时完全退出并重新打开抖音。首页收到新一批推荐时开始处理。以后重新导入配置，在下一批推荐生效。

「隐藏」和「隐藏并反馈」都在手机上隐藏命中项。「只记录」在模块日志记录本批命中数。推荐词按顺序轮换，按可播放的原推荐条数累计间隔，0 表示优先用词条视频替换原推荐。候选在本次刷视频期间去重。文件里的候选用完、过期或无法转换时继续原推荐。修改桌面设置或补充候选都需要重新导出并导入。

兼容适配参考了 DouAi 公布的 40.6.0 推荐数据结构，仅处理首页推荐响应。抖音更新可能改变数据结构。可在 LSPosed 日志查看 `ReviewFeed` 的推荐处理条数或适配错误。实际刷视频时还应核对屏蔽、插入位置和候选播放。[公开适配记录](https://github.com/yudigaga/DouAi/blob/main/app/src/main/assets/douyin-host-rules-40.6.0.tsv)

在极速版 39.3.0（390301）的已安装 APK 中核对过推荐接口路径、推荐列表字段、视频模型以及候选解析方法。尚待在有框架的手机上验证实际屏蔽、插入和播放。

### 免 root 单包版

本地制作的「抖音极速版 39.3.0 推荐流」APK 已内置 LSPatch、推荐流模块和导出时的配置。安装后直接打开极速版即可。这个版本读取包内的配置，要更新屏蔽词、推荐词或插入频率，需要重新导出配置并制作新包。

单包版与官方极速版使用同一个包名，签名不同。在装有官方版的手机上替换时，需先保存本地草稿等资料，再卸载官方版。安装后可能需要重新登录。

### 构建模块

从本目录运行 `./gradlew testDebugUnitTest assembleDebug`。需要 JDK 17 和 Android SDK 37，开发签名模块 APK 位于 `build/outputs/apk/debug/`。制作单包时可用 Gradle 参数 `-PbundledFeedProfile=/绝对路径/抖音推荐流.json` 将配置打入模块。
