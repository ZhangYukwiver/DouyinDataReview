# Android 内容采集与报告

当前 Android 版只提供「内容采集」和「我的报告」，在手机独立运行，不需要电脑采集器或 Metro。

## 安装与使用

安装 `release/DouyinDataReview-Android-arm64.apk`。沿用验证版包名 `com.zhangyukwiver.douyindatareview.proof` 和开发签名，`versionCode` 为 3，可覆盖升级；不要先卸载，否则 Android 会清除应用私有数据和登录状态。本包供本地使用，尚未配置正式发布签名及更新渠道。

1. 点「一键增量采集」，依次更新观看历史、喜欢和收藏。已有完整采集基线时，遇到已有记录后结束该类读取；首次采集或上次中断时，从头补齐当前平台可读记录，再建立完整基线。「完整采集」可主动从头更新三类内容。
2. 正常采集由 Android 原生 HTTP 模块发送请求，复用现有 CookieManager 登录状态和桌面端签名算法，无需网页执行采集。旧版首次升级时会自动加载一次原登录 WebView，取得非敏感请求参数；若需要重新登录或验证，会展示官网。也可主动点「登录 / 验证」。身份验证继续使用「本机极速版验证」入口，由本人确认。
3. 每页保存后继续，可点「停止采集」；切到后台会停止当前轮次。已保存记录保留，但未完成基线不会用于提前停止，下一次会从头补齐，避免中间缺页。每类最多 5 万条，单轮每类最多 5000 页，文件另有容量保护。平台拒绝、限流、账号变化、重复游标或请求超时会停止，不自动重试。无头采集不代表后台常驻服务，采集期间需保持应用在前台。
4. 观看历史保留不同时间的重复观看；喜欢、收藏是本机累计存档，取消喜欢、收藏不会移除已经保存的条目。平台当前可读末页不等于完整历史。
5. 底栏分「概览」「内容」「报告」三页。「内容」页切换观看历史、喜欢、收藏，搜索标题、作者、话题，点一条打开原作品。「概览」页底部点「导出内容 JSON」选择文件夹，可将备份导入桌面版。
6. 「报告」页顶部三张封面直接打开原版「内容年志」「档案馆」「海报」故事页；「概览」页也有年度故事入口。APK 直接打包仓库 `prototype` 中已适配手机的 HTML、动效脚本和竖屏素材，注入本机真实记录，不使用演示数据。故事里的返回按钮会回到原生报告页。
7. 统计报告保留内容概览、近期报告和年度回顾。年份来自可靠行为时间；时间不足时明确显示原因。故事页顶部「导出故事」和统计报告的「导出离线报告」可保存 HTML；故事导出遵守当前隐私开关。JSON 与 HTML 导出使用 Android 系统文件夹选择器。封面等远程图片仍需网络且可能过期，离线字体回退系统字体。

## 数据与报告

- 自动读取并迁移旧验证版 `android-proof/page-*.json`，原文件保留。新数据写入应用私有目录 `android-collections/records-0.json` / `records-1.json`，交替保存并回读校验；写入中断时恢复上一份。
- 新版限制为一个本机账号，采集前后核对身份；另一个网页登录账号不会混入现有记录。Android 自动备份仍关闭。
- 登录 Cookie 由 Android CookieManager 管理，完整 Cookie 请求头不传入 JS。非敏感请求参数与 User-Agent 保存到应用私有设置；签名所需 URL 参数和接口响应仅在进程内桥接，不写入内容文件或日志。新包关闭 Release WebView 调试。同机验证链接只在本人点击时交给极速版，不落盘。
- 报告复用 `src/domain/annualReport.ts`、`livingReport.ts`、`ReportWorkspace.buildReportModel` 与 `src/services/storyData.ts`。明确的观看时间参与时间统计；喜欢、收藏缺少明确操作时间时只参与内容快照，不使用作品发布时间、播放进度更新时间或采集时间替代。
- 报告只描述已采集样本，不推测缺失内容；保存时间与行为时间分开显示。没有移植聊天、创作者中心、直播、AI 解析或 AI 剪辑。

```sh
npm run android:apk
```
