DouyinDataReview 下载与项目介绍

抖音数据导出与年度报告使用指南

用 DouyinDataReview 可以把本人抖音账号可访问的观看历史、喜欢、收藏和好友聊天记录保存到电脑，选择导出 JSON，并生成本地年度报告。它是免费、MIT 许可的非官方开源桌面应用，支持 Windows x64 与 macOS Apple Silicon；面向抖音（Douyin），不支持国际版 TikTok。

由项目维护者 ZhangYukwiver 维护。内容核对：2026 年 10 月 31 日。安装包与实际发布版本以 GitHub Releases 为准。

如何导出抖音观看历史和聊天记录？

先在桌面版首屏扫码并导入本人登录凭据，读取所需记录，再到「设置 → 数据」选择导出内容。输出为 JSON；导出只使用已保存的记录，不会重新读取。勾选聊天时，语音消息会经抖音转成文字写进文件，这一步需要联网并登着原账号。

  1. 从下载页或 Releases 安装对应系统的版本。macOS 首次打开和 Windows SmartScreen 的处理方式见安装说明。
  2. 启动桌面版，在首屏显示二维码，用抖音 App 扫码。核对账号，勾选「读取视频」和／或「读取聊天」，再确认导入。首次默认只勾选视频；要备份聊天，需要同时勾选聊天。
  3. 等待读取完成。新账号的视频读取会分页获取接口当前提供的观看历史、喜欢和收藏；已有完整读取记录的账号重新导入后只补新增。聊天按所选权限整理和接收。
  4. 在「设置 → 数据」点「导出数据」，勾选需要的部分后保存 JSON。聊天默认不勾选；没有勾选的类型不会写入导出文件。转不了的语音保留原消息并注明原因。
  5. 换电脑时，在新电脑的采集器页选择这份备份，再点「并入本机记录」。登录凭据不在备份内；需要继续在线采集时，重新登录并导入。

聊天备份包含已保存的好友消息及会话信息（含群聊统计），不包含群聊正文。接口不再返回的历史数据无法由本工具恢复。

桌面版自带采集器和扫码入口。从源码运行 Web 工作台时，需启动本地采集器，并通过 Chrome 144+、带远程调试开关的 Edge 或 macOS Comet 导入凭据；导入完成后可关闭浏览器。详见 README 快速开始。

能不登录，直接导入抖音官方档案吗？

可以。已有抖音官方「个人信息下载」的 JSON 或 ZIP 时，在采集器页「或者导入个人档案」处选择文件，就能基于该档案生成报告，不需要登录抖音或配置 AI。

官方档案与本应用备份的作用不同：官方档案直接作为本次报告的输入，可分析的内容取决于档案实际字段；此导入在关闭应用后需要重新选择文件。本应用备份则可以通过「并入本机记录」继续保存在当前账号的记录中。不要把官方档案理解为平台保证完整的全部历史。

如何生成抖音年度报告（Douyin Wrapped）？

读取记录或导入档案后，打开报告即可生成自己的年度回顾，不用等平台年度活动，也不用向 AI 服务发送个人记录。

  1. 在「设置 → 界面风格」选择报告风格，再点「打开报告」。内容年志、档案馆和海报是三种可用的年度报告风格。
  2. 查看观看、喜欢、收藏和聊天的统计，以及数据覆盖情况。报告仅使用记录中存在的日期、作者、话题、音乐、时长等信息，不补造缺失记录。
  3. 需要分享时，导出独立 HTML 或 1080 × 1440 PNG。分享前检查报告中显示的昵称、作者、聊天统计等内容。

可以先看内容年志、档案馆和海报的合成数据示例。示例不是实际用户记录，也不是你账号的数据。

哪些数据能保存？哪些不能保证？

DouyinDataReview 的数据来源与功能边界
内容处理方式边界
观看、喜欢、收藏读取本人账号可访问的接口，归一化后保存本机，可选择导出 JSON不保证全部历史；记录缺少日期或字段会影响报告
好友与群聊保存好友聊天，接收新消息；群聊按需在线读取群聊正文不写入记录备份；官方火花状态不等于本地估算
创作者中心展示本人账号的数据总览、作品与粉丝指标；评论管理里可以作者身份发评论和回复按平台当前权限返回；不代表可以查看任意账号的后台数据
视频与图文支持单条下载、批量 ZIP 和图文全部图片下载在线下载需要有效会话和当前账号可访问的作品
年度与持续报告本机计算；持续报告比较最近 30 天，样本不足时回退到 90 天年度回顾仅代表已保存样本；持续报告与年度回顾是不同视图

采集依赖抖音未公开承诺的私有接口，可能失效或触发账号风控。本项目与抖音、字节跳动及其关联主体不存在隶属、授权、合作或认可关系。仅用于本人账号和个人数据管理；不能承诺账号不会受到平台限制。

数据会传到哪里？

个人记录保存和年度报告计算在本机完成，默认不调用任何 AI 服务。可选的 AI 助手装上后，你发的话和它查到的数据会发给你自己配置的模型接口，或交给本机的 Codex / Claude Code。在线采集和互动需要请求抖音。AI 视频解析与剪辑已经拆成独立应用拆片工坊（ReelLab），在桌面版的内容库或探索页点视频上的「送去」按钮，就把那条视频交给它。

抖音 Cookie 和整份个人记录不会交给拆片工坊；AI 助手发出去的是它为回答查到的那些数据。登录凭据和个人备份都应由本人保管。

这些说明依据哪些源码？

本指南依据公开仓库的实现整理。文档描述当前行为，接口可用性仍由抖音决定；具体版本变更见 Releases。

  • 导出勾选项与文件结构：exportData.ts、DataExportDialog.tsx。
  • 登录与记录采集：browserConnection.mjs、directHistory.mjs。
  • 官方档案与年度统计：personalArchiveParser.ts、annualReport.ts。
  • 送去拆片工坊：desktop/reelLab.mjs。
