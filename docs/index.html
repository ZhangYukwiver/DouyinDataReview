能做什么

  • 读取并保存抖音观看历史、喜欢和收藏，关掉窗口后留在托盘里定时补读
  • 实时接收和回复抖音聊天，有续火花看板，能一键给勾选的人续火花
  • 生成抖音年度报告和最近 30 天的持续报告，可以存成分享图
  • 内容库按标题、作者、话题搜索，视频能在应用里播放或下载到本地
  • 全部记录一键导出成 JSON 文件，换电脑也能带走

安装

本机需要装有 Chrome、Edge、Brave 或 Chromium 其中一个，Windows 自带的 Edge 就可以。

macOS：打开 dmg，把「内容数据工作台」拖进「应用程序」。安装包没有开发者签名，第一次打开前先在「终端」里运行下面这行，不然会提示“应用已损坏”：

xattr -cr "/Applications/内容数据工作台.app"

Mac 版没法在应用里自动更新，出新版本时回到这里重新下载，覆盖安装就行，已经采集的数据不会丢。

Windows：运行安装程序。如果弹出 SmartScreen 提示，先点「更多信息」，再点「仍要运行」。以后的新版本可以在应用里直接更新。

核对安装包是否完整（SHA-256）

加速线路由第三方转发。担心文件被改过的话，可以对照下面的校验值：macOS 在终端运行 shasum -a 256 文件名，Windows 在 PowerShell 运行 Get-FileHash 文件名。

常见问题

有没有像 Spotify Wrapped 那样的抖音年度报告？

有。内容数据工作台（DouyinDataReview）用你本机保存的观看、喜欢、收藏和聊天记录生成抖音年度报告，随时都能打开，还能存成 3:4 的分享图。上面「看看长什么样」里有不用安装的示例报告。

怎么导出抖音观看历史和聊天记录？

安装后连上采集器、登录抖音网页版，读取完成后在「设置」里点「导出数据」，观看历史、喜欢、收藏和好友聊天记录会一起存成一个 JSON 文件。换电脑时在新电脑上导入，再点「并入本机记录」就能接着用。

已经用抖音官方「个人信息下载」导出过数据，能直接用吗？

能。在采集器页「或者导入个人档案」那里选官方导出的 JSON 或 ZIP 文件，不用登录就能生成报告。

能批量下载抖音里喜欢和收藏的视频吗？

能。内容库里点「批量下载」进入多选，选好的视频会打包成 ZIP 存到本机；图文作品会下载全部图片。

收费吗？数据会传到哪里？

免费，源码以 MIT 许可开源。读到的记录只存在你自己的电脑上，不接外部 AI，也不发给任何统计或分析服务。

会被封号吗？

没法保证不会。读取用的是你自己登录的抖音网页版会话，但增量读取走的是抖音没有公开承诺的接口，可能失效，也可能触发风控。建议只在自己的账号上用。

In English

Content Data Workbench (DouyinDataReview) is a free, open-source desktop app for Windows and macOS that turns your own Douyin (Chinese TikTok) watch history, likes, favorites and chats into a Wrapped-style year-in-review. It can export everything as JSON, import Douyin's official personal data download, keep chat streaks going and batch-download videos. Your records stay on your computer. The interface is in Chinese.
